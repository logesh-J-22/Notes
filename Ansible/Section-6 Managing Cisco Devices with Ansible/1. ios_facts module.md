# Cisco `cisco.ios.ios_facts` Module - Notes

## What is `cisco.ios.ios_facts`?

The **`cisco.ios.ios_facts`** module is used to collect facts (information) from Cisco IOS devices. These facts can include:

- Device hardware information
    
- Software version
    
- Interface details
    
- VLAN configuration
    
- Routing information
    
- ACLs
    
- Static routes
    
- Other network resources
    

The collected information is stored in the **`ansible_facts`** variable, which can be used later in the playbook.

---

# Playbook Example

```yaml
---
- name: Cisco ios_facts module
  hosts: R1
  gather_facts: false

  tasks:

    - name: Gather info with cisco.ios.ios_facts
      cisco.ios.ios_facts:
        gather_subset:
          - interfaces
        available_network_resources: true
        gather_network_resources:
          - vlans
          - static_routes

    - name: Display facts
      ansible.builtin.debug:
        msg: "{{ ansible_facts }}"
```

## `gather_subset`

```yaml
gather_subset:
  - interfaces
```

Collects only interface-related facts instead of gathering every available fact.

Example information collected:

- Interface names
    
- Interface status
    
- Interface descriptions
    
- MTU
    
- MAC addresses
    
- Speed
    
- Duplex
    
- IP addresses

## `available_network_resources`

```yaml
available_network_resources: true
```

Returns a list of network resources supported by the device and the installed Ansible collection.

This does **not** retrieve the configuration itself.

Example output:

```yaml
ansible_network_resources:
  - interfaces
  - vlans
  - acls
  - static_routes
  - ospfv2
  - l3_interfaces
```

This is useful for discovering which resources can be gathered or managed.

---

## `gather_network_resources`

```yaml
gather_network_resources:
  - vlans
  - static_routes
```

Collects structured configuration for specific network resources.

    - vlan_id: 20
      name: HR

ansible_network_resources:

# Difference Between `gather_subset` and `gather_network_resources`

|`gather_subset`|`gather_network_resources`|
|---|---|
|Collects general device facts.|Collects structured network configuration.|
|Returns variables such as `ansible_net_hostname` and `ansible_net_interfaces`.|Returns data under `ansible_network_resources`.|
|Used for hardware, software, interface, and configuration facts.|Used for resource-specific configurations like VLANs, ACLs, and routes.|

# Summary

- **`cisco.ios.ios_facts`** gathers facts from Cisco IOS devices.
    
- **`gather_facts: false`** disables standard OS fact gathering because network devices use dedicated network modules.
    
- **`gather_subset`** collects general device facts (interfaces, hardware, config, etc.).
    
- **`available_network_resources: true`** lists the network resource types supported by the device and collection.
    
- **`gather_network_resources`** retrieves structured configuration for selected resources such as VLANs and static routes.
    
- All collected information is stored in **`ansible_facts`**, making it available for use in later tasks, conditional logic, templates, and reports.
