# Priority Check

## What happens if we give the Playbook Variables and the Inventory variable name same

**`The program will print the playbook variable as the output`**

we can't able to get the variables from the 1st play to the 2nd play or any other play we will get a error

To load vars from the external files, need to ***use vars_files and need to the location***. If we have multiple variables it's better to add in a folder.

==By default the ansible will search for vars file in the folder vars so if we name the folder vars, we need not give the folder path in the vars_files==

 Now we have created a task to check the precedence between Inventory/external_files/play_vars Variable

==Here the external_files variables takes the precedence.==

Now we ask the user to prompt the input and store using ***vars_prompt*** 

Now we have created a task to check the precedence between Inventory/external_files/play_vars/vars_prompt Variable

==Here again the external_files variables takes the precedence.==

Now we will pass the variables by using extra vars, this will be passes in the cmd line.

```
1. Extra vars (-e)

2. Play vars_files
   
3. Play vars_prompt
   
4. Play vars
   
5. Inventory host vars
```
