# Ansible `map` Filter

## Overview

The **`map`** filter applies an operation to every item in a list and returns an iterator (generator) containing the transformed values.

It is commonly used to:

- Extract attributes from dictionaries.
- Apply another filter to every list element.
- Retrieve values from nested dictionaries.
- Transform lists into a simpler format.

> **Note:** The output of `map` is a generator. If you need a normal list, append the `list` filter:
>
> ```jinja2
> {{ my_list | map(attribute='id') | list }}
> ```

---

# Syntax

## Apply another filter

```jinja2
{{ my_list | map('filter_name', arguments...) }}
```

Example:

```jinja2
{{ names | map('upper') | list }}
```

---

## Extract an attribute

```jinja2
{{ my_list | map(attribute='attribute_name') | list }}
```

---

# Demo Playbook

```yaml
---
- name: Demo on map filter
  hosts: R1
  gather_facts: false

  vars:
    vlan_configuration:
      - id: 100
        name: Marketing
        status: active

      - id: 200
        name: Sales
        status: inactive

      - id: 300
        name: Engineering
        status: active

  tasks:

    - name: Demonstrate map filter
      debug:
        msg:
          - "{{ vlan_configuration }}"
          - "{{ [0] | map('extract', vlan_configuration) }}"
          - "{{ [0] | map('extract', vlan_configuration, 'id') }}"
          - "{{ [0,2] | map('extract', vlan_configuration, 'id') }}"
          - "{{ ['R1'] | map('extract', hostvars, 'ntp_server') }}"
          - "{{ vlan_configuration | map(attribute='id') }}"
```

# Using `map('extract')`

The **`extract`** filter retrieves data from another list or dictionary using keys or indexes.

General syntax:

```jinja2
{{ keys_or_indexes | map('extract', source) }}
```

or

```jinja2
{{ keys_or_indexes | map('extract', source, attribute) }}
```

---

## Example 1 – Extract an Entire List Element

```jinja2
{{ [0] | map('extract', vlan_configuration) }}
```

### Explanation

- Start with a list containing the index:

```yaml
[0]
```

- Use index **0**
- Retrieve the corresponding element from `vlan_configuration`

Result

```yaml
- id: 100
  name: Marketing
  status: active
```

---

## Example 2 – Extract a Specific Attribute

```jinja2
{{ [0] | map('extract', vlan_configuration, 'id') }}
```

### Explanation

1. Go to index **0**
2. Retrieve that dictionary
3. Return only the **id** field

Result

```yaml
100
```

---

## Example 3 – Extract Multiple Attributes

```jinja2
{{ [0,2] | map('extract', vlan_configuration, 'id') }}
```

### Explanation

Index **0**

```
100
```

Index **2**

```
300
```

Result

```yaml
100
300
```

Equivalent list

```yaml
[100,300]
```

---

## Example 4 – Extract Values from `hostvars`

```jinja2
{{ ['R1'] | map('extract', hostvars, 'ntp_server') }}
```

Suppose

```yaml
hostvars:

  R1:
    ntp_server: 192.168.1.10

  R2:
    ntp_server: 192.168.1.20
```

The expression

```jinja2
['R1']
```

selects host **R1**.

Then

```jinja2
map('extract', hostvars, 'ntp_server')
```

retrieves

```yaml
192.168.1.10
```

This is useful for collecting variables from multiple hosts.

Example:

```jinja2
{{ groups['routers'] | map('extract', hostvars, 'ansible_host') | list }}
```

Output

```yaml
- 10.10.10.1
- 10.10.10.2
- 10.10.10.3
```

# Using `map(attribute=...)`

The **`attribute`** option is the most common use of the `map` filter.

Syntax

```jinja2
{{ list_of_dicts | map(attribute='attribute_name') | list }}
```

---

## Example

```jinja2
{{ vlan_configuration | map(attribute='id') }}
```

Result

```yaml
100
200
300
```

Equivalent list

```yaml
[100,200,300]
```

---

## Extract VLAN Names

```jinja2
{{ vlan_configuration | map(attribute='name') | list }}
```

Result

```yaml
- Marketing
- Sales
- Engineering
```

---

## Extract Status

```jinja2
{{ vlan_configuration | map(attribute='status') | list }}
```

Result

```yaml
- active
- inactive
- active
```

# `map(attribute=...)` vs `map('extract', ...)`

## `map(attribute=...)`

Use when you already have a **list of dictionaries** and want to extract the same field from each item.

Example

```jinja2
{{ vlan_configuration | map(attribute='id') | list }}
```

Input

```yaml
[
  {id:100},
  {id:200},
  {id:300}
]
```

Output

```yaml
[100,200,300]
```

---

## `map('extract', ...)`

Use when you have **keys or indexes** and want to retrieve values from another list or dictionary.

Example

```jinja2
{{ [0,2] | map('extract', vlan_configuration, 'id') | list }}
```

Input

```yaml
Indexes:
[0,2]
```

Output

```yaml
[100,300]
```

# Common Use Cases

## Collect interface names

```jinja2
{{ interfaces | map(attribute='name') | list }}
```

---

## Collect IP addresses

```jinja2
{{ interfaces | map(attribute='ip') | list }}
```

---

## Collect inventory IPs

```jinja2
{{ groups['routers'] | map('extract', hostvars, 'ansible_host') | list }}
```

---

## Convert strings to uppercase

```jinja2
{{ users | map('upper') | list }}
```

---

## Convert numbers to strings

```jinja2
{{ numbers | map('string') | list }}
```

---

# Best Practices

- Use **`map(attribute=...)`** for extracting values from a list of dictionaries.
- Use **`map('extract', ...)`** when you have indexes or dictionary keys and need to retrieve corresponding values.
- Append **`| list`** when you need the results as a standard list.
- Combine `map` with filters like `selectattr`, `rejectattr`, `unique`, and `sort` for powerful data transformations.

---

# Summary

| Expression | Purpose |
|------------|---------|
| `map(attribute='id')` | Extract an attribute from every dictionary in a list |
| `map(attribute='name')` | Extract names from a list of dictionaries |
| `map('extract', list)` | Retrieve elements by index |
| `map('extract', list, 'id')` | Retrieve a specific attribute from selected elements |
| `map('extract', hostvars, 'ansible_host')` | Retrieve host variables from the inventory |
| `map('upper')` | Apply another filter to every element |

---

# Key Takeaway

The **`map`** filter is one of the most versatile Jinja2 filters in Ansible. Use **`attribute`** when extracting the same field from every dictionary in a list, and use **`extract`** when you need to look up values from another list or dictionary using indexes or keys. Combined with filters like `selectattr`, `rejectattr`, and `list`, `map` enables concise and expressive data transformations in playbooks.
