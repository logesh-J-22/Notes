
The `ansible.cfg` file is Ansible's **configuration file**. It tells Ansible **how to behave by default**, so you don't have to specify the same options every time you run a playbook.

For example, instead of running:

```
ansible-playbook -i inventory.ini playbook.yml --private-key ~/.ssh/id_rsa
```

you can define those settings in `ansible.cfg` and simply run:

```
ansible-playbook playbook.yml
```

### Common settings in `ansible.cfg`

```
[defaults]inventory = inventory.ini
host_key_checking = False
remote_user = admin
timeout = 30
forks = 10
[ssh_connection]
pipelining = True
```

Here's what these settings do:

|Setting|Purpose|
|---|---|
|`inventory`|Specifies the default inventory file.|
|`host_key_checking = False`|Disables SSH host key verification (useful in labs; be cautious in production).|
|`remote_user`|Sets the default SSH username.|
|`timeout`|Defines the SSH connection timeout in seconds.|
|`forks`|Controls how many hosts Ansible manages in parallel.|
|`pipelining`|Improves SSH performance by reducing the number of operations per task.|

### Where Ansible looks for `ansible.cfg`

Ansible searches for a configuration file in this order:

1. `ANSIBLE_CONFIG` environment variable (if set)
2. `ansible.cfg` in the **current working directory**
3. `~/.ansible.cfg` in your home directory
4. `/etc/ansible/ansible.cfg`

The first one it finds is the one it uses.
```
export ANSIBLE_CONFIG=~/ansible_main
```

## Generate the **ansible.cfg**: 

```
ansible-config init --disabled > ansible.cfg
```

### What it does

- `ansible-config init` generates a template `ansible.cfg`.
- `--disabled` writes **all available configuration options as commented-out entries**.
- `>` redirects the output into a file named `ansible.cfg`.

The resulting file looks something like:

```
[defaults]
#inventory=/etc/ansible/hosts
#host_key_checking=True
#remote_user=root
#forks=5
```

All options are commented out, so Ansible ignores them until you uncomment and modify the ones you need.

For example, you might change it to:

```
[defaults]
inventory = inventory.ini
host_key_checking = False
remote_user = admin

[ssh_connection]
pipelining = True
```

### Other useful option

If you want a file containing **only the active/default settings** rather than every possible option, you can use:

```
ansible-config init > ansible.cfg
```

### Which should you use?

- `ansible-config init --disabled` → **Best for learning.** You can browse every configurable option with explanations.
- `ansible-config init` → Better if you want a shorter starting file.
- Manually creating a small `ansible.cfg` → Common for most real-world projects, since only a handful of settings are typically needed.
